# Hardware licensing

This repository is source-available for noncommercial use. `REUSE.toml` is the
machine-readable file map and `LICENSES/` contains the complete license texts.

Original hardware design documentation, configuration, evidence and supporting
data are licensed under `CC-BY-NC-SA-4.0`. The license permits noncommercial
copying, modification and redistribution with attribution and share-alike
terms. It does not grant commercial use.

This repository currently documents a research prototype; it does not provide a
complete manufacturing package or a safety-certified design. Copyright in
drawings and documentation does not necessarily control independently created
functional hardware, and the CC license grants no patent or trademark rights.
