# Illumination Option Matrix

| Option | Use | MVP? | Notes |
|---|---|---:|---|
| Central white LED | BF imaging | yes | needs flat-field/color calibration |
| Red/green oblique LEDs | single-shot AF | yes | based on R/G shift calibration |
| Programmable RGB LED array | flexible AF angles | likely later | helpful for angle sweeps |
| NIR reflected-interface AF | active focus | future | measures interface, requires sensor/path |
| Laser triangulation | active height | future | beware transparent layers/multiple reflections |
| Confocal/chromatic/LCI | high-end depth sensing | future | robust but complex/expensive |
| mmWave radar | autofocus | no | wrong scale/modality for current goal |
