# LED Mount Rev A

## Goal

Provide adjustable white and red/green LED placement for early brightfield and autofocus experiments.

## Geometry

Use the simple relation:

```text
NA_illum ≈ r / sqrt(r^2 + h^2)
```

Place red and green symmetrically. Prefer red/green axis perpendicular to scan axis.

## Requirements

- Adjustable lateral offset.
- Stable height relative to slide.
- Space for diffuser/collimator experiments.
- Mechanical repeatability.
- Easy replacement of LEDs.
